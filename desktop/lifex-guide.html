LIFEX

初回面談 実践ガイド

セミナー後 着座〜ヒアリング フロー
このガイドの使い方：セミナー終了後、お客様に着座いただいたタイミングから使います。
各フェーズを順に進めながら、「教える」ではなく「気づかせる」会話を心がけてください。
価格・仕様の話は お客様自身が必要性を感じてから。補足資料（コスト比較など）はフェーズ6以降で使います。
PHASE 1 アイスブレイク 5〜10分 ▾
このフェーズのゴール 緊張をほぐし、「この人なら話せる」と感じてもらう。信頼関係のベースをここで作る。
話題の切り口
Q
「今日はどちらからお越しですか？お車でしたか？」
道中の話から自然に入る。答えやすい質問でリラックスさせる。
Q
「今日のセミナー、いかがでしたか？気になった部分はありましたか？」
セミナーへの感想を聞くことで、何に関心があるか自然につかめる。
Q
「お子さんは今おいくつですか？どんなお子さんですか？」
家族の話は誰でも喜んで話す。写真を見せてもらえたら最高。
Point この段階でLIFEXの話・仕様の話は一切しない。相手の話を聞く比率8割を意識する。「そうなんですか」「それは大変でしたね」「いいですね」——相槌を大切に。
次のフェーズへの橋渡し 「せっかくですので、もう少しじっくりお話を聞かせていただいてもいいですか？今日のゴールは、○○様ご家族にとって"いい判断"ができるようにお手伝いすることですので。」
PHASE 2 理想の暮らしを聞く 15〜20分 ▾
このフェーズのゴール お客様自身の言葉で「叶えたい暮らし」を語ってもらう。ここで出てきたキーワードを、あとのフェーズで必ず使う。
聞くべき質問
Q
「家を建てたいと思われたきっかけは何ですか？」
動機を聞く。「子供が生まれた」「今の家が寒い」「賃貸がもったいない」など、後で共感できるポイントが出てくる。
Q
「今のお住まいで、一番不満に感じていることは何ですか？」
ネガティブな動機を引き出す。「寒い」「光熱費が高い」「音が気になる」は性能の話に直結する。
Q
「新しい家で、どんな生活がしたいですか？具体的に想像してみてください。」
答えをメモする（ヒアリングシートに記入）。「子供が庭で遊べる」「家族がリビングに集まる」「老後も住める」——この言葉をあとで引用する。
Q
「その家で、何年暮らしたいですか？」
長期の視点を持ってもらう問いかけ。「30年・40年」が出てきたら「健康」「ランニングコスト」の話に自然につながる。
Point 答えは必ずメモする。「それは素敵ですね」で肯定し続ける。修正や反論は絶対にしない。ここで出たキーワードが、このあとの会話の「軸」になる。
次のフェーズへの橋渡し 「○○様のおっしゃる暮らし、ぜひ実現してほしいです。その暮らしを30年・40年続けるために、少し確認させてください。」
PHASE 3 気づきを与える問いかけ 20〜25分 ▾
このフェーズのゴール 「家の性能の重要性」にお客様自身が気づく。教えるのではなく、質問によって「考えさせる」。このフェーズが最も重要。
注意 「うちはこういう性能があります」という話は、まだしない。質問して、お客様に考えてもらい、「そうなんですか！」を引き出すことだけ意識する。
空気・健康について
Q
「ご家族でアレルギーや花粉症、喘息をお持ちの方はいらっしゃいますか？」
→ 「実は、新築でも換気の仕組みが正しくないと、室内の空気は改善されないんです。ご存知でしたか？」
Q
「壁の中で結露が起きると、どうなると思いますか？」
→ 「カビ・シロアリ・家の傷みに直結します。でも見えないから気づいたときには手遅れで。気密シートはその対策なんですが、建てる前に確認する方はほとんどいないんです。」
光熱費・快適さについて
Q
「今の家で、冬に廊下や洗面所が寒いと感じますか？」
→ 「実は断熱と気密がセットになっていないと、暖房をかけていても温まらない家になります。今、光熱費は月どれくらいかかっていますか？」
Q
「30年・40年住むとして、光熱費の総額を考えたことはありますか？」
→ 「月2万円の差で、35年だと約840万円変わります。家の価格と同じくらい、住んでからのコストが大事なんです。」
地震・安全について
Q
「最近の地震のニュース、気になりますよね。"耐震等級3"という言葉は聞いたことがありますか？」
→ 「耐震と制震って、実は違うんです。耐震だけだと揺れに"耐える"だけで、繰り返しの揺れには弱い。制震ダンパーがあると揺れを"吸収"します。」
Point お客様が「そうなんですか？」「知らなかった」と言ったら成功。答えを急がず、少し間をおいて考えてもらう。「怖い話」にならないよう、あくまで「大事な話」として穏やかに伝える。
次のフェーズへの橋渡し 「これ、家づくりで一番確認しなければいけないことなんです。さっき○○様が『（Phase2のキーワードを引用）』とおっしゃっていましたよね。実はそれを叶えるために、こういう性能が必要で——」
PHASE 4 性能を「暮らし」に繋げる 10〜15分 ▾
このフェーズのゴール お客様の"叶えたい暮らし"と各性能項目を紐づける。「スペック説明」ではなく「あなたの夢を実現するための条件」として話す。
暮らしと性能の結びつけ方
→
「健康に長く住みたい」 とおっしゃっていましたね
→ 第一種換気システム＋防湿気密シートが必須です。この2つがないと、新築でも空気の質は変わりません。
→
「光熱費を抑えたい」 とおっしゃっていましたね
→ 断熱性能（UA値）と気密性能（C値）がセットで高くないと意味がありません。片方だけでは効果が出ない。
→
「地震に強い家に住みたい」 とおっしゃっていましたね
→ 耐震等級3＋制震ダンパーがセットで必要です。等級だけでは繰り返しの揺れに対応できない。
→
「長く住み続けられる家」 とおっしゃっていましたね
→ 防蟻処理（ホウ酸）＋壁体内結露ゼロが前提です。見えない部分が家の寿命を決めます。
Point 必ずPhase2で出てきたお客様の言葉を引用してから話す。「うちにはこれがあります」ではなく「○○様の希望を叶えるために、これが必要なんです」という順番を絶対に守る。
次のフェーズへの橋渡し 「ここまで話してみて、○○様はどう感じましたか？もし他社さんも見てみようと思われているなら、ぜひ確認してほしいことがあります。」
PHASE 5 他社への問いかけ — 気づきを持ち帰ってもらう 5〜10分 ▾
このフェーズのゴール お客様が自分で他社に確認したくなる状態を作る。比較ではなく「判断基準を渡す」イメージで。
他社に確認してほしいこと（渡せるリスト）
気密シートは施工しますか？
換気システムは第一種ですか？（熱交換型ですか？）
耐震等級は何等級ですか？（許容応力度計算で出していますか？）
制震ダンパーはついていますか？
UA値とC値を数字で見せてもらえますか？
防蟻処理は何を使いますか？（農薬系ですか、ホウ酸ですか？）
壁体内結露の対策はどのようにしていますか？
Point 「LIFEXはこれが全部できます」という言い方はしない。「この質問に全部答えてもらえる会社で建ててください。それが絶対条件です」という言い方に留める。お客様自身が気づく余白を残す。
やってはいけないこと 他社の悪口を言わない。「A社はここが弱い」という話をしない。あくまで「判断の軸を渡す」だけ。
次のフェーズへの橋渡し 「今日のお話を踏まえて、○○様のご家族にとっての"いい家"が少し具体的になりましたか？もし次のステップを一緒に考えていただけるなら、もう少し具体的なプランをお持ちします。」
PHASE 6 LIFEXで進める意思決定へ 5〜10分 ▾
このフェーズのゴール（第一目標） 今日の面談で「LIFEXで進めます」という意思決定をいただく。補足資料（コスト比較など）が必要であればここで使う。
Q
「今日のお話を通じて、LIFEXで家を建てることをご検討いただけそうですか？」
直接的に意思を確認する。ここを曖昧にしたまま終わらせない。
→
補足資料（光熱費・保険・防蟻のコスト比較）が必要であれば見せる
「さっきのお話を数字でも確認してみますか？」という切り出しで。押し売りにならないよう、必要性を感じたときに出す。
即決いただけなかった場合 — 必ずやること 「今日は決められない」という場合、理由を曖昧にしたまま終わらせない。
「何が一番気になっていますか？」と必ず聞く。
意思決定できない理由の引き出し方
Q
「今日すぐに決めにくい、一番の理由は何ですか？」
答えをそのままメモする。「金額」「他社も見たい」「家族に相談」「まだ時期ではない」——それぞれで次回の対応が変わる。
Q
「その不安が解消されたら、LIFEXで進める気持ちはありますか？」
YESなら次回面談は「その不安を取り除く場」と明確に設定できる。NOなら別の理由が隠れている。
2回目面談の設定方法 「では次回は、今日出た○○というご不安を一緒に解消する時間にしましょう。」と具体的に約束する。漠然と「また来てください」で終わらせない。次回の議題をお客様自身の言葉で決める。
今日の面談終了後に必ずメモすること ①お客様が語った「叶えたい暮らし」のキーワード　②意思決定を妨げている不安の具体的な内容　③次回面談で解消すべきテーマ。この3点が次回の信頼構築の土台になる。
