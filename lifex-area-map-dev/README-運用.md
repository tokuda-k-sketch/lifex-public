# LIFEX 加盟エリアマップ 運用手順

## 全体像

```
加盟店にヒアリング → スプシ「施工範囲マスタ」に入力 → 地図を開けば自動反映
                                （GAS がJSON配信・再デプロイ不要）
```

一度セットアップすれば、日々の運用は**スプシに行を足す・消すだけ**。

---

## 初回セットアップ（30分・1回だけ）

### 1. スプレッドシートを作る
1. Googleスプレッドシート新規作成 →名前「LIFEX施工範囲マスタ」
2. タブを2つ作る：
   - **施工範囲マスタ**（入力用）… `施工範囲マスタ_雛形.csv` を「ファイル→インポート→現在のシートに追加」
   - **市区町村マスタ**（プルダウン用）… `市区町村マスタ.csv` を同様にインポート（全1,896市区町村）

### 2. 入力ミス防止のプルダウンを設定
- 施工範囲マスタのB列（都道府県）: データ→データの入力規則→リストを範囲で指定 → 市区町村マスタのA列
- C列（市区町村）: 同様に市区町村マスタのB列を範囲指定
  ※「全域」「堺市」のような展開ワードは警告が出るが「入力を確定」で入る（規則は「警告を表示」にしておく）
- D列（区分）: リストを直接指定 →「エリア購入済,施工可能」

### 3. GASをデプロイ
1. スプシの 拡張機能 → Apps Script
2. `lifex-area-apps-script.js` の中身を貼り付け
   （コピーはPowerShellで `Get-Content lifex-area-apps-script.js -Raw -Encoding UTF8 | Set-Clipboard`。
   エンコード指定なしだと日本語が文字化けして構文エラーになる）
3. デプロイ → 新しいデプロイ → 種類：ウェブアプリ → アクセス：**全員** → デプロイ
4. 発行された `https://script.google.com/macros/s/…/exec` をコピー

### 4. 地図に接続して公開
1. `index.html` の上の方にある `const GAS_URL = '';` にURLを貼る
2. ブラウザで開いて確認 → バッジが緑の「スプシ連携｜自動反映」になればOK
3. `index.html` と `map-data.js` の2ファイルをNetlifyにドロップ（KPIダッシュボードと同じ）

---

## 日々の入力（基本は地図でクリック）

手元で `index.html` を開くと右上に「**✏ 施工範囲を入力**」ボタンが出る（公開URLでは出ない。出したいときはURL末尾に `#edit`）。

1. ボタンを押す → 右のパネルで**加盟店**を選ぶ（新規は「＋新しい加盟店を追加…」）
2. **いま塗る区分**（エリア購入済／施工可能）を選ぶ
3. 県をクリックで拡大 → **市区町村をクリックで塗る。もう一度クリックで消す**
4. 県まるごとなら「**○○県をまとめて選択**」ボタン（他社の購入済は自動でスキップ）
5. 「**💾 スプシに保存**」→ 初回だけPIN（合言葉、GASコード内の `PIN`。初期値 lifex2026）を聞かれる
6. スプシはその加盟店の行が自動で差し替わる（全域・政令市全区は「全域」「堺市」に自動圧縮、備考欄に入力日時が入る）

他社の購入済エリアを塗ろうとすると確認が出る。加盟店の登録を全部消したいときは、その加盟店を選んで全部クリックで消して保存（0行保存＝削除）。

## スプシに直接入力する場合のルール（手入力もこれまで通り使える）

1行＝1エリア。列は「加盟店名／都道府県／市区町村／区分／備考」。

| 書き方 | 例 | 意味 |
|---|---|---|
| 正式名 | 川口市、堺市堺区、いの町 | その市区町村だけ（郡名は付けない） |
| 政令市名だけ | 堺市 | 全区にまとめて展開（20政令市対応） |
| 全域 | （都道府県=高知県）全域 | 県内すべての市区町村 |

- **区分**は「エリア購入済」か「施工可能」。購入済が常に優先表示
- **政令市の2分割**が決まったら、「堺市」1行を消して「堺市堺区」「堺市中区」…と区単位の行に書き直す
- 施工可能が複数社で重なるのは正常（地図は縞模様で表示）。**購入済の重複はエラー**として画面上部に警告が出る
- 地名の打ち間違い・存在しない組み合わせ（例:大阪府なのに市区町村が埼玉の市）は、その行だけ反映されず画面上部に黄色い警告が出る → スプシを直してリロード

## 反映のタイミング
- スプシを直したら、地図ページを**リロードするだけ**（GASの再デプロイは不要）
- Netlifyへの再ドロップが必要なのは index.html 自体を変えたときだけ

## 商談用の小技
- URLに `#pref=大阪府` を付けるとその県を開いた状態で始まる（例: `https://○○.netlify.app/#pref=大阪府`）
- `&mode=member` を足すと加盟店別色分けで開く
